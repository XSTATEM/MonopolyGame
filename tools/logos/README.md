# Логотипы компаний (tools/logos)

`build-logos.mjs` собирает логотипы всех 31 компании игры в
`server/public/logos/` и пишет туда же `logos.json`:

```json
{
  "AAPL": {"file":"AAPL.svg","color":"#000000","source":"simple-icons:apple"},
  "IBM":  {"file":"IBM.png","color":"#0071C5","source":"board:r5c8"},
  ...
}
```

- `file` — имя файла в `server/public/logos/` (`.svg` или `.png`);
- `color` — основной цвет бренда (hex), например для обводки или фона-заглушки;
- `source` — откуда взят логотип (см. ниже).

Скрипт без npm-зависимостей: PNG читается и пишется встроенным `zlib`. Пакет
`simple-icons` нужен только на время сборки и в `server/package.json` **не
добавляется** — готовые файлы лежат в репозитории, и для игры ничего
устанавливать не нужно.

## Запуск

Один раз поставить `simple-icons` во временную папку (не в проект):

```powershell
# PowerShell
npm install --prefix "$env:TEMP\tm-logos" simple-icons@16.35.0
node tools/logos/build-logos.mjs --si "$env:TEMP\tm-logos\node_modules\simple-icons"
```

```bash
# bash
npm install --prefix /tmp/tm-logos simple-icons@16.35.0
node tools/logos/build-logos.mjs --si /tmp/tm-logos/node_modules/simple-icons
```

Вместо `--si` можно задать переменную окружения `SIMPLE_ICONS_DIR`.
Скрипт выверен на simple-icons **16.35.0**; на другой версии он предупредит —
иконку могли перерисовать или удалить, стоит проверить контактный лист.
Сборка детерминирована: повторный запуск даёт те же байты.

| параметр | что делает |
|---|---|
| `--si <папка>` | пакет simple-icons (папка с `icons/` и `data/simple-icons.json`) |
| `--board <png>` | фото физического поля, по умолчанию `maps.png` в корне |
| `--out <папка>` | куда писать, по умолчанию `server/public/logos` |
| `--contact <файл.html>` | контактный лист для ревью: все логотипы 16/24/40/64 px на белом, на цвете поля, на цветах секторов и на белой плашке |
| `--review <папка>` | для тикеров-вырезок — все их клетки на поле, обработанные, полосой в PNG (чтобы выбрать самую чистую) |
| `--only AAPL,SBER` | собрать только эти тикеры (остальные записи `logos.json` сохраняются) |

## Источники

Что откуда берётся, задано таблицей `LOGOS` в начале скрипта.

**simple-icons** (`source: "simple-icons:<слаг>"`, SVG, viewBox 24×24) — 18 шт.:
AAPL, NVDA, INTC, SONY, NFLX, META, VKCO, MCD, NKE, KO, SBUX, ADS, BA, TSLA,
MMM, AFLT, F, V. Путь иконки заливается цветом бренда из simple-icons; у Sony
там `#FFFFFF`, поэтому цвет заменён на чёрный.

**Своя геометрия** (`source: "svg:<имя>"`, SVG 24×24) — функции `DRAW` в скрипте:

- **MSFT** — четыре квадрата в фирменных цветах (Microsoft из simple-icons удалён);
- **GOOGL** — контур «G» из simple-icons, раскрашенный секторами в четыре цвета Google
  (в simple-icons он одноцветный);
- **PEP** — упрощённый глобус Pepsi (красный верх, белая волна, синий низ): Pepsi нет
  ни в simple-icons, ни на поле;
- **SBER** — кольцо с градиентом и галочка; геометрия снята с клетки поля, цвета — в
  фирменной гамме. На поле логотип Сбера с 3D-тенью и свечением — вырезка
  получалась грязной.

Это упрощённые перерисовки, а не официальные файлы брендов.

**Поле** (`source: "board:r<ряд>c<колонка>"`, PNG до 128 px по большей стороне) —
9 шт.: IBM, AMZN, DIS, YDEX, WMT, RKT (Durex), GAZP, MGNT, MTSS. Этих брендов нет в
simple-icons (удалены или не добавлялись), но они есть на фото поля `maps.png`.
Ряды на поле нумеруются 1..12 сверху вниз, колонки — 12..1 слева направо (как
подписано на самом поле).

Как делается вырезка:

1. PNG декодируется (8 бит, RGB/RGBA, фильтры 0–4).
2. Сетка ищется по тёмно-бирюзовым линиям: столбцы и строки, где таких пикселей
   больше половины максимума, — 13 вертикальных и 13 горизонтальных линий.
3. Из клетки берётся часть над подписью тикера (подпись находится по её цвету),
   без светлого ободка у линий сетки.
4. Фон клетки (лёгкий градиент — аппроксимируется плоскостью по краю вырезки)
   удаляется заливкой от пикселей чистого фона; фото пересвечено, поэтому светлая
   кайма вокруг логотипа тоже считается фоном. Полупрозрачный край считается
   «матированием» по соседнему пикселю логотипа, контур перекрашивается в цвет
   пикселя поглубже — без бирюзовой и белой каймы на тёмном фоне.
5. Мелкий мусор убирается, прозрачные поля обрезаются, картинка уменьшается до
   128 px по большей стороне усреднением по площади (box filter) и пишется в PNG
   (фильтр 0, zlib).

У AMZN белая «a» на белом фоне не видна — светлые пиксели перекрашиваются в
фирменный тёмно-синий `#232F3E`, контур дополнительно сглаживается.

Если логотип в выбранной клетке касается края вырезки (залез на ободок или на
подпись), скрипт предупредит. Другую клетку удобно выбрать так:

```
node tools/logos/build-logos.mjs --si <...> --review review-out --only YDEX
```

— в `review-out/YDEX.png` все клетки Яндекса слева направо в порядке, напечатанном
в консоли; помеченные «(обрезан?)» лучше не брать. Номер клетки — в `LOGOS`.

## Как показывать в клиенте

- SVG — квадрат 24×24 с логотипом по центру; PNG обрезаны по содержимому и
  бывают не квадратными (Disney, IBM, Walmart). Показывать в квадратной рамке с
  `object-fit: contain` (или `background-size: contain`).
- Тёмные логотипы (Apple, Nike, Adidas, Sony, Disney, Ford, Visa, Boeing, Аэрофлот)
  почти не видны прямо на цветах секторов, а синие (VK, Intel, Meta, Газпром) и
  зелёные (Сбер, Starbucks) сливаются с «своим» сектором. Надёжнее белая или
  кремовая плашка под логотипом — она показана в последней колонке контактного листа.
- Длинные словесные знаки (Sony, Intel, Coca-Cola, Disney, Visa, IBM) при 16 px не
  читаются — для мелких размеров лучше оставить аббревиатуру.
- Как сделано в игре: `logoHtml()` и клетки поля в `server/public/index.html` кладут
  на цвет сектора кремовую плашку с логотипом (по краю остаётся рамка цвета
  сектора); если файла нет или он не загрузился — видна прежняя аббревиатура.
  Имена файлов — в `LOGO_FILES` там же. После пересборки с новым набором файлов
  обновить `LOGO_FILES`, список `SHELL` в `server/public/sw.js` (и поднять
  `VERSION`) — расхождение ловит `node server/test/check.js`.
  `mobile/scripts/copy-web.mjs` копирует папку `logos/` в приложение сам.

## Лицензии и товарные знаки

- **simple-icons** распространяется под CC0 1.0 (общественное достояние) —
  см. `LICENSE.md` и `DISCLAIMER.md` в пакете. CC0 относится к самим SVG-файлам
  проекта, а не к изображённым знакам: у отдельных иконок могут быть свои условия
  использования, указанные в данных пакета. У использованных здесь иконок в
  версии 16.35.0 поля `license` нет; для Netflix, Meta, VK, Starbucks и Google
  в данных указаны ссылки на брендбуки (`guidelines`).
- **Все логотипы — товарные знаки их владельцев.** Они используются только для
  обозначения соответствующих компаний в игре; игра не связана с этими компаниями
  и не одобрена ими.
- Вырезки из `maps.png` взяты с оформления физического поля игры; перерисовки
  (Microsoft, Google, Pepsi, Сбер) — упрощённые изображения знаков, сделанные для
  этой игры.
